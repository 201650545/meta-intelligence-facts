# 用户语境下的“可视化看板/可画”特指 Obsidian Canvas (.canvas) 原生画布文件

- **类型**：user_correction
- **触发信号**：用户提到“可视化看板”、“可画”、“驾驶舱大白板”、“大目标小目标拆解看板”等概念时。
- **结论与正解**：
  1. 不得单纯用 Markdown 内嵌 Mermaid 或外部 HTML 交付，必须在子目录生成 `.canvas` (Obsidian Canvas JSON 格式) 原生白板文件；
  2. 结构与格式规范严格参照 `D:\Work\AI精听训练器\00_项目驾驶舱_可视化中心\项目演进大白板.canvas`；
  3. 必须包含左侧垂直指挥总枢纽 (Header, KPI, Legend) 与横向领域 Group 泳道，节点必须用 edges 正确连线并标注颜色代码 (3=黄/推进中, 4=绿/已完成, 5=紫/远期, 6=红/指挥枢纽)；
  4. 需配套 WBS 树状分解与多维度交互图表库。
- **错误样本/反面例子**：只在普通 Markdown 文档里写 mermaid 图表，或者误以为用户指的是第三方在线设计网站“Canva可画”。
- **适用范围**：全局用户工程规范
- **记录时间**：2026-09-20
