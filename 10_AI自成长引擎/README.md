## 这是什么

一套让 Agent **在陪我干活的过程中自动变强**的策略与工具：不用我事后专门整理，对话里出现的问题、纠正、踩坑、跑通的操作链，会被自动识别为可复用资产，提炼成三个层级 —— **L1 经验条目 / L2 工作流 SOP / L3 可执行脚本与 skill** —— 并写入既有真源，下次同类问题出现时自动被召回使用。

它要解决的核心痛点是：**好方法只活在那一次对话里**。我现在已经用 `loomy-learned-*` 系列技能证明了"沉淀"有效，但那三个技能全靠我手工写。本项目的全部价值，就是把"沉淀"这一步也自动化，同时对齐 handbook 的单写真源与安全红线纪律，避免自动化变成记忆污染。

**边界**：不做无人审校的自动部署（L2 出草稿待确认、L3 必须人工点头 + dry-run）；不新造第 4 个知识存放地（只写 `D:\记忆` / 项目仓 / 本项目 `技能库\`（经点头才装入程序技能目录） / handbook）；不存凭据明文。
